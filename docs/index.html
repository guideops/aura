Mission control for your AI agents

AURA turns a swarm of coding and research agents into something you can actually watch, steer and stop — a 3D office where every agent is a robot at a desk, every risky tool call waits at a security gate, and every decision lands on one kanban board.

Free · one-click installer · runs entirely on your machine · unsigned build (SmartScreen: More info → Run anyway)

🏢

A live 3D office, not a log file

Every agent is a robot with a status: at a desk when working, at the security gate when blocked, at the council table in review. Rearrange the whole office in the built-in Space CAD editor — agents follow the furniture.

🛡️

Approval guardrails

Dangerous tool calls pause the agent and light up the gate. Approve or deny from the office; the agent resumes or backs off. Policy by architecture, not by prompt.

📋

One kanban, synced to GitHub

Cards spawn real agent sessions with equipped skills. Progress animates live, review lands automatically, and two-way GitHub Projects sync keeps the team's board honest.

🗂️

Obsidian-native memory

Agent memory is plain markdown in a folder Obsidian can open. Full-text search, wikilink graph, auto-written daily briefs — and one-click vault adoption from paired apps.

🖥️

Terminals and usage, live

Per-session terminal streaming, a colored event log, per-model token tracking and system health — the IDE-style command center around the office.

🔗

Pairs with your stack

Provider-agnostic by design: Claude Code sessions out of the box, Nous Hermes via API, and a 6-digit pairing flow so companion apps stream their agents into the same office.

Running in minutes

Download, run the installer, and AURA boots its own local daemon — no accounts, no cloud. Point it at your Obsidian vault, drop a card on the board, and watch the first robot walk to its desk.
