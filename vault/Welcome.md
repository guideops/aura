# Welcome to your AURA Vault

This folder is plain markdown. AURA reads and writes it; point [[Obsidian]] at the
same folder and both see identical notes. No lock-in, no proprietary format.

Agents write memory here as they work — decisions, learnings, and daily [[Briefs]].
Wikilinks like `[[Obsidian]]` become edges in the knowledge graph view.

## How it compounds

Each run leaves residue. The residue improves the next run.
